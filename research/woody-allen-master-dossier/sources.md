# How to read this register

Every source listed here was **actually consulted on 2026-11-02**. Sources that would be
valuable but were not reached are listed under *Research Gaps*, not here.

Each entry gives:

```
ID / Source / Publisher or organisation / URL or reference / Source type /
Date / Primary information verified / Reliability notes
```

## Reliability classes used

| Class | Meaning | Use |
| --- | --- | --- |
| **A — First-party** | Published by Woody Allen or Gravier Productions | Authoritative for intent and for archive inventory; **not** automatically correct on fact (see the audit below) |
| **B — Institutional** | Film archives, award bodies, foundations, government open data, theatre databases | The highest factual confidence in this dossier |
| **C — Reputable trade and press** | *Variety*, *Deadline*, *The Hollywood Reporter*, *The Bookseller*, *Playbill*, *Euronews*, major newspapers | Strong for dated events; weaker for credits |
| **D — Reference encyclopedias** | Cross-checked reference articles | Useful and used extensively; **never the sole authority for a publication-sensitive claim where a better source exists** |
| **E — Dedicated specialist sites** | Long-running single-subject sites (location research, discography) | Careful but unaccredited; corroborate where possible |
| **F — Enthusiast and commercial listings** | Fan sites, retailer pages, blogs | Used only where nothing better exists, always flagged, never for a quotation |

## IDs S010–S019 — reserved

**Deliberately unassigned.** They are reserved for the **primary film-credit sources** that
must be added to close gap **G-CREDITS-01**: title-by-title AFI Catalog records, BFI
records, on-screen end credits, and distributor press kits. Assigning them now, in a block
adjacent to the one existing AFI record [S009], keeps the register's shape legible when
that work is done.

## Reading of the legacy site

It is **two sites layered on top of each other**. An older, image-heavy archive of
scanned screenplays, cast bios and poster art survives on some film pages — *Annie Hall*
being the fullest. A newer, text-heavy press-kit treatment exists on the most recent film
— *Coup de Chance*. Between them, most pages have neither. **The rebuild should take the
*Coup de Chance* page's text depth and the *Annie Hall* page's archive depth as the two
targets, and should not treat any page's labels or links as correct without checking.**
